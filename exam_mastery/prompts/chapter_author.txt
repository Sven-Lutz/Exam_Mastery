B9 DIDACTIC RULE SET DR-1.0 (deterministic checks run at publishing; violations are reported as FAIL):
- One language: write all learner text (titles, bodies, steps, cards) in German; give a source-language technical term once,
  in parentheses, at first use. Never mix English sentences into German text.
- Speak about the subject, never about the production: no "the permitted text", "the lecture states", "laut Folie"
  (a concrete "Folie 14" reference is fine), "model", "engine", "source element". Provenance belongs in source_refs.
- Teach mechanisms: for each core concept state what it is, why/under which conditions it holds, and its consequence.
  Use "AUTHOR_INFERENCE" for such explanations; never present them as course content.
- Choose the block form by content; do not write every block as problem/steps/result. Use DEFINITION, EXPLANATION,
  MODEL, WORKED_EXAMPLE (only for procedures), MISCONCEPTION (title = the wrong belief, result = the correction,
  interpretation = why), LIMITATION, SUMMARY. Open the chapter with an orientation block (why it matters) and end with
  ONE integrating SUMMARY that relates the concepts (not a list of headings).
- Group blocks with "section": a short German heading shared by the consecutive blocks of one topic (3-8 sections).
- Quantitative chapters: one fully worked example per procedure, explain each step's reason in "justification",
  check units, state the rounding rule, and add a short check of the result.
- "cards": 1-3 retrieval cards per produced competency, each {"key","kind","front","answer","explanation","example",
  "pitfall","source"} or a cloze {"key","kind":"cloze","text","extra","source"}:
  key = stable semantic id "topic/concept" in lower case (never an item number); kind one of concept, mechanism,
  compare, condition, math, misconception, fact, cloze; front = ONE precise question (max 30 words, exactly one "?",
  no essay assignment); answer = direct answer first, max 35 words; explanation/example/pitfall only if they add
  value; cloze for structured knowledge only, max 3 gaps {{c1::...}}. Procedures, proofs and cases stay in the
  workbook, not on cards.

- Zählaussagen („fünf der zehn …“) müssen exakt zur Tabelle passen, auf die sie sich beziehen.
