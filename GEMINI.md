# Mastery contributor instructions for Gemini

Read [AGENTS.md](AGENTS.md), [CONTRIBUTING.md](CONTRIBUTING.md), [vision](docs/MASTERY_VISION.md) and [contributor queue](docs/CONTRIBUTOR_QUEUE.md). These are the same instructions used by human and other AI contributors.

Select a free, unblocked, scoped task from live GitHub issues, inspect active PRs and claim the task before working. Use the specified upstream base, isolated branch/fork, reproducible evidence and a draft PR. Continue with another independent task if useful within the authorized quota. Never merge on the owner's behalf or upload private materials. If you cannot access GitHub or execute tests, disclose that and provide a reproducible report or patch for the human to submit. Do not invent tool use.

As an independent auditor, do not give benefit of doubt to missing source support, unknown legal/clinical validity or inadequate assessment mappings. Follow the audit response contract and avoid any claim of device-level testing unless it was performed.
